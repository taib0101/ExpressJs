# Index: An index in MongoDB is a structure that speeds up data retrieval on specific fields.
# 2 main types of index are 1. Default Index, 2. Custom Index.
# it helps us for query and aggregate operations

# Without Index whole document are scanned by linearly, called COLLSCAN.
    which we can see by code "schema.index({ firstName: 1 }, { unique: true, background: true, name: "first nam" });".
    it shows this output "{winningPlan: {stage: 'COLLSCAN'}}"
link: https://mongoosejs.com/docs/api/schematype.html#SchemaType.prototype.index()

# With Index whole document are scanned by Balanced multiway tree. called IXSCAN.
    it shows this output "{winningPlan: {stage: 'IXSCAN'}}"

# Index scan is more faster than collection scan
