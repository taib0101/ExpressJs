2. Express Js packages
	$ npm install express
	$ npm install cookie-parser
	$ npm install cors
	$ npm install express-rate-limit (prevent DDOS attack)
	$ npm install helmet (for security issue)
	$ npm install hpp (prevent url parameter pollution attack)
	$ npm install jsonwebtoken (authenticate web token)
	$ npm install mongoose (work with mongo DB)
	$ npm install nodemailer (work with mail)
	$ npm install nodemon
	$ sudo npm install -g nodemon
